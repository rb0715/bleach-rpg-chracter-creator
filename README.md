# bleach-rpg-chracter-creator
A Bleach inspired text adventure in Python: build your character, pick your faction and powers, then fight your first Hollow in story mode.

## How to play
Answer each prompt by typing one of the options shown in parentheses, then press Enter. Spelling matters ( Going to add speller checker and suggestions soon )


## Practiced
- User Input & String handling
- Conditionals
- Function
- Using game design to sttructure a larger program
